# IA Gate v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. The repo workflow `.claude/workflows/implement-plan.js` automates the subagent-driven loop.

**Goal:** Build the IA Gate: a Python MCP server on a PC that lets Claude Code / Claude Desktop identify Android devices by a stable gate ID and install, launch, observe and test apps on them through adb.

**Architecture:** One Python process = MCP server (`MCPServer`, stdio or Streamable HTTP) + JSON device registry + async adb client. Devices are enrolled once (fingerprint + marker file) and resolved to their current adb serial on every call; per-device locks serialize operations.

**Tech Stack:** Python ≥ 3.11, `mcp>=2.3,<3`, `uvicorn`, `tomllib`, `uv`, `pytest` + `pytest-asyncio` (asyncio_mode = auto), `ruff`.

**Spec:** `docs/superpowers/specs/2026-10-29-ia-gate-design.md`

## Global Constraints

- All gate code lives in `gate/` (uv project, package `ia_gate` under `gate/src/ia_gate/`, tests in `gate/tests/`). Run commands from `gate/`.
- Python ≥ 3.11; runtime deps limited to `mcp>=2.3,<3` and `uvicorn`.
- MCP API: `from mcp.server.mcpserver import MCPServer, Image`; errors via `from mcp.server.mcpserver.exceptions import ToolError`; tests use `from mcp.client import Client` (`async with Client(server) as c`). Note: `server.call_tool` raises `ToolError` directly; through `Client` it returns a result with `is_error=True`.
- No test may call a real `adb`: every adb interaction goes through the injected `Runner`.
- Device ID regex `^[A-Z0-9][A-Z0-9_-]{1,31}$`, normalized to upper case.
- Marker path `/data/local/tmp/.ia-gate-id`.
- Invalid serialnos: `""`, `"unknown"`, `"0123456789ABCDEF"`, `"0123456789"`, or shared by ≥ 2 connected devices.
- Every argument passed to `adb shell` is `shlex.quote`d by `AdbClient`.
- Default config values exactly as spec §7.
- Error messages are in French and actionable (spec §8).
- Each task ends with `uv run pytest -q` and `uv run ruff check .` green, then one commit.

## Review Focus

- A device whose `ro.serialno` is bogus (`0123456789ABCDEF`) or shared with another connected device must never be confused with it: resolution falls back to marker / android_id (tests in Tasks 3 and 5).
- A device in `unauthorized` or `offline` state must produce the actionable message, not a raw adb error (Task 5).
- `apk_path` outside `apk_dirs`, via `..` or a symlink, or not ending in `.apk`, must be refused before any adb call (Task 7).
- Two concurrent tool calls on the same device must run one after the other; on different devices, concurrently (Task 5).
- Huge logcat output must be truncated to `max_log_bytes`, keeping the most recent lines, with a visible truncation notice (Task 8).

### Task 2: Async adb client

**Files:**
- Create: `gate/src/ia_gate/adb.py`, `gate/tests/fakes.py`
- Test: `gate/tests/test_adb.py`

**Interfaces:**
- Consumes: nothing.
- Produces:
  - `@dataclass(frozen=True) class AdbResult(returncode: int, stdout: bytes, stderr: bytes)` with property `text -> str` (stdout decoded utf-8, `errors="replace"`).
  - `Runner = Callable[[Sequence[str], float], Awaitable[AdbResult]]` and `async def subprocess_runner(args, timeout) -> AdbResult` (asyncio subprocess; kills on timeout and raises `AdbTimeout`; `FileNotFoundError` → `AdbNotFound`).
  - `@dataclass(frozen=True) class TransportId(value: int)` (`str()` → `"transport_id:N"`) and `Target = str | TransportId` — how a per-device command is addressed: an adb serial → `adb -s SERIAL`, a `TransportId` → `adb -t N`. `-t` is required when several connected devices share one adb serial (spec §4: a batch reporting `0123456789ABCDEF` over USB), since adb refuses `-s` with `more than one device`.
  - `@dataclass(frozen=True) class AdbDevice(serial: str, state: str, model: str | None, transport_id: int | None = None)` with `target(duplicated_serials: Collection[str] = ()) -> Target` (`TransportId` when `serial` is in `duplicated_serials` and `transport_id` is known, else `serial`).
  - `duplicate_serials(devices: Iterable[AdbDevice]) -> frozenset[str]` — adb serials listed more than once.
  - Errors: `class AdbError(Exception)`, `AdbTimeout(AdbError)`, `AdbNotFound(AdbError)`, `InstallError(AdbError)` with attribute `code: str`.
  - `class AdbClient(runner: Runner, adb_path: str = "adb", timeout_s: float = 120)`:
    - `async devices() -> list[AdbDevice]` (parses `adb devices -l`; `model:` token → model with `_` → space; `transport_id:N` → `transport_id`, absent/non-numeric → None)
    - `async shell(serial: Target, args: Sequence[str], timeout: float | None = None) -> AdbResult` (runs `[adb, -s, serial | -t, N, shell, *map(shlex.quote, args)]`; non-zero → `AdbError` with stderr/stdout)
    - `async exec_out(serial: Target, args: Sequence[str]) -> bytes` (`exec-out`, same quoting)
    - `async getprop(serial: Target, name: str) -> str` (stripped)
    - `async install(serial: Target, apk_path: Path, replace: bool = True) -> None` (`install [-r] path`; output containing `Failure [CODE...]` → `InstallError(code=CODE)`)
    - `async uninstall(serial: Target, package: str) -> None`
    - `async connect(host: str, port: int) -> str` (returns adb's message; `failed`/`unable` in output → `AdbError`)
  - `tests/fakes.py`: `class FakeRunner` — `on(prefix: list[str], stdout: str|bytes = "", returncode: int = 0, stderr: str = "")` registers a response matched on the args *after* `adb -s SERIAL` / `adb -t N` when the call is device-scoped, else after `adb`; optional `serial: Target | None` restricts it to one target; `calls: list[list[str]]`; unmatched call → `AssertionError` naming the args; optional `delay: float` per response (for lock tests).

### Task 5: Device resolver (status, resolution, locks, enrollment)

**Files:**
- Create: `gate/src/ia_gate/resolver.py`
- Test: `gate/tests/test_resolver.py`

**Interfaces:**
- Consumes: `AdbClient.devices` (Task 2), `read_fingerprint`, `read_marker`, `write_marker`, `normalize_device_id` (Task 3), `DeviceRegistry` (Task 4).
- Produces:
  - `@dataclass(frozen=True) class DeviceStatus(device_id: str | None, adb_serial: str | None, state: Literal["online","offline","unauthorized","disconnected"], label: str, model: str | None)`.
  - `class DeviceUnavailable(Exception)` — message is the actionable French text of spec §8.
  - `class DeviceResolver(adb: AdbClient, registry: DeviceRegistry)`:
    - `async snapshot() -> list[DeviceStatus]` — one entry per enrolled device (disconnected if absent) plus one per connected unenrolled device (`device_id=None`). Fingerprints are cached per adb serial and evicted when the serial leaves `adb devices`. Ambiguous serials are computed over the online devices of this snapshot.
    - `async resolve(device_id: str) -> Target` — returns the adb target of the online device (`AdbDevice.target(duplicate_serials(devices))`: a `TransportId` when its adb serial is shared by several connected devices, else the adb serial); every per-device adb call of the resolver (fingerprint, marker) uses that same target; raises `DeviceUnavailable` for unknown / disconnected / unauthorized / offline; calls `registry.remember_serial` with the adb serial.
    - `lock(device_id: str) -> asyncio.Lock` — one lock per normalized ID.
    - `async enroll(adb_serial: str, device_id: str, label: str, now: str) -> DeviceRecord` — device must be online; reads fingerprint, `registry.enroll`, `write_marker`. When several connected devices share an adb serial, `snapshot()` reports their `adb_serial` as `str(TransportId)` (`transport_id:N`) and `enroll` accepts that form to pick one; a bare duplicated serial → `DeviceUnavailable` asking for the `transport_id:N` form.
